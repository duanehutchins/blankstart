## What this repo is
Offline-first React + TypeScript + Vite expo demo for Xerge.

## Why it exists
Teach Xerge positioning fast at booths and capture consented leads locally for export.

## Run locally
1. `npm ci`
2. `npm run dev`

## Build and checks
- `npm run typecheck`
- `npm run test`
- `npm run build`
- `npm run lint`
- `npm run wayfinder:check`
